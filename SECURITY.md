# Security

Report vulnerabilities privately under the
[MNX bug bounty policy](https://docs.mnx.fi/security/bug-bounty). That page
sets out the scope, the rewards, the testing rules, and how to contact the team.
Contact details are also in
[security.txt](https://docs.mnx.fi/.well-known/security.txt).

Do not open a public GitHub issue or pull request for a vulnerability, and do
not test against mainnet in ways the policy forbids.
